# Belgian Household Electricity Consumption Analysis

This project was completed as part of the **Project Learning from Data (PLFD)** course in the Master of Statistics and Data Science program at Hasselt University.

## Project Overview

The objective of this study was to identify the key factors associated with household electricity consumption in Belgium. Using a dataset of Belgian households, exploratory data analysis, data quality assessment, and multiple linear regression techniques were applied to investigate how household characteristics influence annual electricity usage.

## Methods

The analysis included:

* Exploratory Data Analysis (EDA)
* Data Cleaning and Quality Assessment
* Multiple Linear Regression
* Model Selection using Akaike Information Criterion (AIC)
* Diagnostic Evaluation of Model Assumptions
* Interpretation of Statistical Results

Model assumptions, including normality, homoscedasticity, and multicollinearity, were systematically evaluated to ensure the validity of the final model.

## Key Findings

The final regression model identified occupancy, EPC label, and dwelling size as the primary factors associated with household electricity consumption. These variables explained approximately **89% of the variation** in annual household electricity use.

The analysis showed that larger households and larger dwellings generally consume more electricity, while building energy efficiency characteristics also play an important role in explaining consumption differences across households.
